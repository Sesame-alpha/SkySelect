# SkySelect

Responsive flight seat booking UI built with HTML, CSS, and JavaScript.

## Features
- Aircraft seat map: Business class (rows 1–3, 2-2 layout) and Economy (rows 4–20, 3-3 layout)
- Center aisle and class divider labels
- Seat states: available, selected, occupied, business (gold outline)
- Live fare summary by class with running total
- Booking persists via localStorage (seats stay taken after refresh)
- Fully responsive, mobile-friendly grid
